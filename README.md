# tesseract-updates

Sparkle update feed for [Tesseract](https://github.com/ArianHobson333/tesseract-macos).
Served with GitHub Pages at `https://arianhobson333.github.io/tesseract-updates/`.

`mac/appcast-arm64.xml` is written only by the Tesseract release workflow, after the
DMG passes notarization checks; every item carries an EdDSA signature. DMGs are
hosted on the tesseract-macos GitHub Releases. Don't edit the feed by hand.
